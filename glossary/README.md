# SAP-C02 Glossary

AWS SAP-C02では、AWSサービス名だけでなく、ネットワーク、Web、認証、データ、DR、運用の一般用語を読めることが前提になる。この用語集は、問題文の制約語をAWSのサービス選択へ変換するためのもの。

## 使い方

1. 長文問題で知らない単語に出会ったら、この用語集へ戻る。
2. 単語の意味だけでなく「SAP-C02での判断」を確認する。
3. 対応するサービスページや比較表へ移動する。
