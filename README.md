# AWS Mastering

150以上のAWSサービスを体系的・実践的にまとめたリポジトリです。

SAP-C02合格 + 実務アーキテクト力向上を目指す人に最適化されています。

## 特徴
- Tiered Approach（最重要サービスを深く解説）
- サービス間の繋がりと対比表
- 実践アーキテクチャパターン
- SAP-C02学習ロードマップ

## フォルダ構成
- `services/` - 各AWSサービス詳細
- `comparisons/` - サービス対比表
- `patterns/` - 組み合わせパターン
- `LEARNING_PATH.md` - 体系的学習順序

詳細は[LEARNING_PATH.md](./LEARNING_PATH.md)を参照してください。
