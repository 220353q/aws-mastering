# Contributing to AWS Mastering

Thank you for your interest in improving this repository!

## How to Contribute
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-addition`)
3. Make your changes (new service page, comparison, pattern, or improvement)
4. Ensure content follows the Tiered Approach and quality standards (3-5 high-value use cases, clear connections, Well-Architected alignment)
5. Submit a Pull Request with clear description

## Content Guidelines
- **Tier 1 services**: Minimum 5 detailed use cases + full connections + Well-Architected section
- **Comparisons**: Use tables with clear recommendations
- **Patterns**: Include architecture diagram (ASCII or Mermaid), key services, benefits, and SAP-C02 relevance
- **Language**: Japanese or English (currently bilingual-friendly)

## Questions?
Open an issue or contact the maintainer.

**Let's build the best AWS architecture resource together!**
