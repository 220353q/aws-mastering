# SAP-C02 Practice

このフォルダは、読む教材を「解く教材」に変えるための演習置き場。

## 方針

- 長文シナリオ型
- 選択肢は本番に近いサービス組み合わせ
- 正解だけでなく、誤答がなぜ魅力的に見えるかを解説する
- 1問ごとに、判断軸・構成図・関連サービスページへのリンクを付ける
- Set 02以降は、A〜Gの7択・正解1〜3個の形式で作成

## 推奨の使い方

1. 問題文だけを読み、本文中の制約語に下線を引く。
2. A〜Gを読む前に、必要なサービス候補を自分で3〜5個書く。
3. 選択肢ごとに「なぜ正しいか / なぜ違うか」を一文で説明する。
4. 解説の構成図を見て、本文の制約がどこに反映されているか確認する。
5. 関連リンクからサービスページへ戻り、誤答理由をノート化する。
6. 模試後は `weakness-diagnosis.md` で誤答タイプを記録する。
