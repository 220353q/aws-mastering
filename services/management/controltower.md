# AWS Control Tower

## Overview
Managed service to set up and govern a secure, compliant multi-account AWS environment (landing zone) with best practices built-in.

## Key Features
- Automated landing zone setup (Organizations + IAM Identity Center + Guardrails)
- Guardrails (preventive + detective) based on Well-Architected
- Account Factory (self-service account provisioning)
- Dashboard for compliance status
- Integration with Organizations, IAM Identity Center, CloudTrail, Config

## Use Cases (Tier 1 - Enterprise)
1. **Enterprise Landing Zone** - Secure multi-account foundation in hours
2. **Compliance Governance** - Preventive guardrails (deny non-compliant actions)
3. **Self-Service Account Provisioning** - Account Factory with guardrails
4. **Audit & Compliance Reporting** - Centralized dashboard + evidence
5. **Merger Integration** - Quickly onboard new accounts with governance

## Connections
- **Organizations + IAM Identity Center**: Core identity & governance
- **GuardDuty + Security Hub + Config**: Detective controls
- **CloudTrail + CloudWatch**: Audit & monitoring
- **Service Catalog**: Approved products

## Well-Architected
- Security: Built-in guardrails + least privilege
- Governance: Preventive + detective controls
- Compliance: Automated evidence collection
- Operational Excellence: Self-service with guardrails
