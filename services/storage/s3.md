# Amazon S3

## Overview
Amazon Simple Storage Service (S3) is object storage with 99.999999999% durability. Unlimited scale, multiple storage classes.

## Key Features
- Storage Classes (Standard, IA, Glacier, Deep Archive, Intelligent-Tiering)
- Versioning, Lifecycle Policies, Replication (CRR/SRR)
- Encryption (SSE-S3, KMS, SSE-C)
- Object Lock, MFA Delete
- Event Notifications, Static Website Hosting
- S3 Select, S3 Inventory

## Use Cases (Tier 1 - Selected 5)
1. **Static Website Hosting** - S3 + CloudFront + Route 53 (cost-effective, global)
2. **Data Lake / Analytics** - Raw data zone for Glue/Athena/Redshift Spectrum
3. **Backup & Archive** - Lifecycle to Glacier, Cross-Region Replication
4. **Application Assets** - Images, videos, user uploads with presigned URLs
5. **Log Aggregation** - Centralized logs with S3 Select for querying

## Connections
- **CloudFront**: CDN acceleration
- **Glue + Athena**: Data lake analytics
- **Lambda**: Event triggers (upload processing)
- **IAM**: Bucket policies, access control
- **KMS**: Encryption
- **CloudWatch**: Metrics, logging
