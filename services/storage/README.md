# Storage Services

## Tier 1
- **Amazon S3** (detailed: s3.md) - Object storage
- **Amazon EBS** - Block storage for EC2
- **Amazon EFS** - File storage

## Tier 2/3
- Amazon FSx, AWS Storage Gateway, S3 Glacier, AWS Backup, AWS Snow Family

**Key Decision**: S3 for unstructured/object, EBS for block, EFS for shared file.
