# Compute Services

## Tier 1 Services
- **Amazon EC2** - Virtual servers (detailed page: ec2.md)
- **AWS Lambda** - Serverless compute (detailed: lambda.md)
- **AWS Fargate** - Serverless containers
- **Amazon ECS** - Container orchestration
- **Amazon EKS** - Kubernetes

## Tier 2
- AWS Batch, AWS App Runner, Amazon Lightsail, AWS Elastic Beanstalk, AWS Outposts, AWS Wavelength

## Usage Tips
EC2 for control, Lambda for scale, Fargate for containers without ops.
