# Amazon SageMaker

## Overview
Fully managed ML platform. Build, train, deploy, and monitor models at scale. Includes Studio, Pipelines, Feature Store, Clarify, Model Monitor.

## Key Features
- SageMaker Studio (IDE)
- Built-in algorithms + bring-your-own
- Training jobs, Hyperparameter tuning, Distributed training
- Endpoints (real-time, batch, serverless inference)
- Pipelines, Feature Store, Model Registry, Clarify (bias/explainability), Model Monitor
- JumpStart, Canvas (no-code), Autopilot

## Use Cases (Tier 2 - High Value)
1. **Custom Model Training & Deployment** - Studio + Training Jobs + Endpoints
2. **MLOps Pipeline** - SageMaker Pipelines + Model Registry + Monitoring
3. **Feature Store for Real-time Inference** - Feature Store + Lambda/Endpoints
4. **No-Code ML** - Canvas + Autopilot for business users
5. **Responsible AI** - Clarify for bias detection + explainability

## Connections
- **S3**: Data storage
- **Glue / Athena**: Data prep
- **Lambda / API Gateway**: Inference endpoints
- **CloudWatch + X-Ray**: Monitoring
- **EventBridge**: Pipeline triggers
