# SAP-C02 Exam Tips & Domain Breakdown

## Domain Weightings (approximate)
- Domain 1: Design Solutions for Organizational Complexity (26%)
- Domain 2: Design for New Solutions (29%)
- Domain 3: Continuous Improvement (25%)
- Domain 4: Accelerate Workload Migration and Modernization (20%)

## High-Yield Topics
- Multi-account strategies (Organizations, Control Tower, IAM Identity Center)
- Well-Architected Framework (all pillars, especially Security & Reliability)
- Serverless patterns (Lambda + API Gateway + DynamoDB + Step Functions)
- Global architectures (Route 53, CloudFront, Global Accelerator, Aurora Global, DynamoDB Global Tables)
- Cost optimization (Savings Plans, Spot, Intelligent-Tiering, right-sizing)
- Migration strategies (Strangler Fig, Blue/Green, Rehost/Replatform/Re-architect)
- Security services integration (GuardDuty + Security Hub + WAF + KMS)

## Common Question Patterns
- "Which combination of services..." (choose 2-3 services for a scenario)
- "What is the MOST cost-effective / secure / reliable..."
- Scenario-based with business requirements (RTO, compliance, scale)

## Study Recommendations
1. Master Tier 1 services deeply (this repo)
2. Practice patterns/ and comparisons/
3. Review Well-Architected whitepapers
4. Hands-on labs (Qwiklabs, AWS Skill Builder)
5. Practice exams (official + third-party)

**Pass rate tip**: Focus on design trade-offs, not just service features.
